Présentation du concept

Bienvenue dans Du code à l'écran, un web-documentaire consacré à l'univers du développement web. À travers cette émission, nous allons découvrir comment sont conçus les sites Internet, depuis les premières lignes de code jusqu'à leur mise en ligne.

HTML, CSS, JavaScript, mais aussi le développement côté serveur : chaque épisode nous fera découvrir une facette de ce métier passionnant. Que vous soyez débutant, étudiant ou simplement curieux du numérique, vous découvrirez les coulisses du Web.

Programme de la saison

  1. HTML : les fondations du Web
  2. CSS : donner vie aux pages web
  3. JavaScript : rendre les sites interactifs
